Color Code Logic Puzzle

Rosewood Cipher Atelier

Deduce the secret color sequence using precise feedback clues. White peg means perfect match, black peg means right color wrong position.

Rosewood Cipher Atelier is a single-player logic deduction game where you crack hidden color codes within a limited number of attempts. Each guess returns immediate feedback: exact match and color only, letting you narrow the solution with pure reasoning.

Main Menu

Start a Classic game, tackle the Daily Challenge, or review your statistics.

Make Your Guess

Select colored balls from the palette and place them in sequence, then submit to verify.

Read the Clues

White pegs show exact matches. Black pegs show correct colors in wrong positions. Use logic to refine your next attempt.

Multiple Difficulties

Progress from 4-ball beginner puzzles to harder challenges with more colors and longer codes.

Features

Pure Logic Gameplay

No luck needed — every puzzle is solvable through deduction. Analyze feedback, eliminate possibilities, and crack the code.

Clear Feedback System

Each guess returns white pegs (exact matches) and black pegs (color-only matches), giving you precise information to work with.

Progressive Difficulty

Multiple modes with varying code lengths and color pools. Beginners start with 4 balls; experts face longer sequences.

Daily Challenge

A new shared puzzle every day. Solve the same code as players around the world and compare your efficiency.

Track Your Skills

View solve streaks, best attempt counts, and personal statistics to measure your logical reasoning improvement.

Offline & Private

Play anywhere without internet. No ads, no accounts, no tracking, and no data collection.

How to Play

1. The game secretly selects a sequence of colored balls.
2. You place your guess by selecting colors and arranging them in order.
3. Tap Verify to submit your guess.
4. Receive feedback: a white peg means one ball is correct in both color and position; a black peg means a color exists in the code but is placed in a different slot.
5. Use the clues to refine your next guess. Crack the code before you run out of attempts!
